# 🩻 Chest X-ray Abnormality Detection System

An AI-powered web application prototype for chest X-ray image analysis using **YOLOv8 and Deep Learning**. The system provides an interactive image-upload interface, visualizes predicted abnormality regions, displays an application-generated severity level, and generates downloadable PDF reports.

## 📌 Project Overview

Chest X-ray images are widely used in medical imaging to help evaluate thoracic conditions. This project demonstrates how computer vision and deep learning can be integrated into a web application to visualize model predictions and organize analysis results into a report.

The application combines a Flask-based backend, a web interface, an object-detection pipeline, and PDF report generation in a single workflow.

## ✨ Key Features

- **Chest X-ray Upload:** Enter a patient label and upload an X-ray image.
- **YOLOv8-Based Detection:** Run the configured object-detection model on the uploaded image.
- **Detection Visualization:** Display predicted regions using bounding boxes and class labels.
- **Severity Display:** Show the severity level generated by the application.
- **Explainability Visualization:** Display a heatmap when supported by the current implementation.
- **PDF Report Generation:** Generate and download a report containing analysis results and image visualizations.
- **Web-Based Interface:** Interact with the application through a Flask-powered web interface.

## ⚙️ Application Workflow

1. **Image Upload:** The user enters a patient label and uploads a chest X-ray.
2. **Image Processing:** The backend receives the image and prepares it for inference.
3. **Model Inference:** The configured YOLO model generates predicted detections.
4. **Result Visualization:** The application displays the image with predicted bounding boxes and labels.
5. **Severity Display:** The application presents its configured severity output.
6. **Report Generation:** The user can download a PDF summary of the results.

## 🚀 Installation and Execution

### Prerequisites

- Python 3.12
- pip
- Git

### 1. Clone the repository

```bash
git clone https://github.com/KunapuliBalaSriSarvani/chest-xray-abnormality-detection.git
cd chest-xray-abnormality-detection
```

### 2. Create and activate a virtual environment

For Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

After a verified `requirements.txt` has been added to the repository, run:

```bash
python -m pip install -r requirements.txt
```

### 4. Configure model weights

Ensure the required model weights are available at the path expected by `inference.py`. Confirm the model filename and class mapping before running the application.

### 5. Start the application

```bash
python app.py
```

Open the local URL displayed in the terminal.
